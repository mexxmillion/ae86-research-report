# AE86 visual research report

Public article: https://mexxmillion.github.io/ae86-research-report/

A static, editorial presentation of the AE86 reconstruction experiments. Includes selected images, videos, and web GLB previews. The asset remains in review; local editable masters and execution logs are not part of this repository.

GLBs are web copies with quantized attributes; textured previews use textures limited to 2048 pixels. No intentional mesh simplification was requested.
